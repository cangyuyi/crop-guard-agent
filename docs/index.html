这是方法演示，不是农事工具。 合规判定跑的是仓库内 data/ 的公开查询小快照 （中国农药信息网，2026-10-10 拉取），可能过期或不全，覆盖范围也有限。 真实用药请以手中产品标签与当地植保站指导为准。本页面不构成农药使用建议。

这个页面在跑真代码

页面通过 Pyodide 在浏览器里加载并运行本仓库的 src/cropguard/， 数据读自 data/。不是截图、不是预设结果——你输入什么，规则就跑什么。

跑的是哪一个实现：确定性规则实现（rule_based）。 依赖模型的那条路径（llm_assisted）需要 API key，无法在浏览器里跑。

因此你可能撞到两次已知的天花板。点「番茄价格今年走势怎么样」会看到它追问而不是拒答—— 规则实现的域外判定只看词汇，看到「番茄」就判成域内，但它问的是价格。 点「柑橘黄龙病」那条，说明里会带一句名录条目尚未核对公告文号的提醒—— 那是真实的数据缺口，不藏着。 这两件事在 llm_assisted 路径上的表现见仓库 README 的三数据集矩阵。
